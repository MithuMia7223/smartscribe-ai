# SmartScribe AI - Global Deployment Guide

## 🌍 World Wide Live Hosting Instructions (100% Free)

This project is fully configured for instant global deployment on Vercel and Render.

### Option 1: Render.com (Recommended for Node.js Express Backend)
1. Go to [Render.com](https://render.com) and log in with Google/GitHub.
2. Click **New +** -> **Web Service**.
3. Connect your GitHub repository or upload this folder (`smartscribe-ai`).
4. Render will automatically detect `render.yaml`.
5. Click **Deploy Web Service**.
6. Your live global link will be created instantly: `https://smartscribe-ai.onrender.com`

### Option 2: Vercel.com
1. Go to [Vercel.com](https://vercel.com).
2. Click **Add New Project**.
3. Import the `smartscribe-ai` folder.
4. Click **Deploy**.
5. Your live link will be created instantly: `https://smartscribe-ai.vercel.app`

## 🔍 Google Search Console Registration
After deployment:
1. Open [Google Search Console](https://search.google.com/search-console).
2. Add your live URL (e.g., `https://smartscribe-ai.onrender.com`).
3. Submit `sitemap.xml` (`https://smartscribe-ai.onrender.com/sitemap.xml`).
4. Google will index the site worldwide!
